# Vaelen Music

一个基于 **Vue 3 + Vite + Tauri v2** 的跨平台桌面音乐播放器，兼容 lx-music 风格的第三方音源脚本。安装后占用磁盘大小仅约10MB。

本质上是对lx-music-desktop的Tauri移植版，不过对前端进行了重构。

支持多音源聚合（网易云 / QQ 音乐 / 酷我 / 酷狗 / 咪咕）、在线搜索、歌单/榜单、高清音质下载、全屏播放页与多主题外观。

## 特性

### 播放
- **多音源聚合搜索**，内置源 **官方接口直连**，不依赖第三方脚本
- **支持自定义导入** lx-music 兼容音源脚本（丰富播放/歌词/封面能力）
- **音质选择**：`128K / 320K / FLAC / 24Bit / Hi-Res / Master`
- **音质自动降级**：当前音源无法播放指定音质时，自动降档播放并提示（master → hires → flac24bit → flac → 320k → 128k）
- **歌词跨源兜底**：本源无歌词时，自动从其他音源搜索同名歌曲补全歌词
- 内置源优先、失败自动回退音源脚本

### 界面
- 全屏 NowPlaying 播放页：滑入动画、上下滑手势开关、歌词跟随高亮
- 收藏/**我的歌单**体系，可自建列表
- 下载独立页：选择清晰度下载，支持进度/重试
- 4 套主题（1 深 3 浅）：`午夜`（深色玻璃）/ `纸本`（暖纸衬线）/ `霓虹`（浅色赛博直角）/ `极光`（浅色大圆角渐变）

### 工程
- 桌面端（Tauri）与 Web 模式（Express 服务端）双形态
- 数据持久化：用户数据保存于 `%APPDATA%\com.vaelen.music\settings.json`（Web 模式为 localStorage）
- 打整体积优化：按需引入 crypto-js、Rust release 优化（安装包约 2.4 MB）

## 快速开始

### 桌面应用（Tauri）

```bash
npm install
#开发模式
npm run tauri dev     
#或打包：
npm run tauri build   
```

产物位于 `src-tauri/target/release/bundle/`。

### 本地 Web 模式

```bash
npm install
npm run dev:full      # 同时启动 Express 服务端(3210) 与 Vite(5173)
```

浏览器访问 `http://localhost:5173`。

### 测试

```bash
npm test              # 自动化冒烟测试（puppeteer-core，需本机 Edge/Chrome）
```

## 使用说明

1. **搜索与播放**：顶部选择音源（内置源：kw/kg/wy/tx/mg），输入关键词搜索，点击歌曲加入播放队列。
2. **导入音源脚本**：设置页可导入 lx-music 兼容脚本（`import` 区块），为某个音源提供更完整的搜索/歌词/封面能力。
3. **下载**：播放条/搜索列表的下载按钮会弹出**清晰度选择**，按所选格式命名文件（FLAC 系使用 `.flac`）。
4. **主题切换**：设置页选择主题，立即生效并持久化。

## 常见问题

- **部分歌曲无法播放**：免费接口对 VIP/付费内容受限，会提示"该歌曲无法播放"，并自动尝试低音质或回退脚本源。请支持正版。
- **音质被降级**：当前音源可能不提供所选高音质（如 Hi-Res），应用会自动降级到可用档并提示原因。
- **歌词缺失**：已自动从其他音源搜索补全；若全部音源均无，则显示"暂无歌词"。
- **导入脚本后无效**：确认脚本为 lx-music 兼容格式，重开软件后生效。

## 目录结构

```
├── src/                   # 前端（Vue 3 + Pinia + Vue Router）
│   ├── components/        # PlayerBar / NowPlaying / QualityPicker 等
│   ├── views/             # SearchView / DownloadsView / SettingsView 等
│   ├── music-sdk/         # 内置音源实现（搜索/播放/歌词/封面/歌单/榜单）
│   ├── runtime/           # lx-music 脚本运行时
│   └── styles/            # main.css + themes.css（4 套主题）
├── server/                # Web 模式 Express 后端（内置源 + 脚本运行时）
├── src-tauri/             # Tauri v2 桌面壳（Rust）
└── tests/                 # 自动化冒烟测试
```
